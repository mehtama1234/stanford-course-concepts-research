# First-Principles Extraction Rubric

This layer is built for explanation, not lecture summarization. A lecture is evidence; the atlas is a cross-course map of the ideas that keep reappearing.

## Extraction Standard

Each concept must answer six questions:

1. What everyday problem is this idea solving?
2. Why does that problem exist in the first place?
3. What is the mathematical lever underneath the method?
4. What becomes possible once the idea exists?
5. What breaks without it?
6. Which transcript evidence supports the claim?

## Plain-Language Rules

- Start with the concrete problem before naming the technical term.
- Introduce jargon only after the plain-language meaning is already stated.
- Equations are allowed only when each symbol is explained in ordinary language.
- Avoid generic claims such as "improves performance" unless the mechanism is stated.
- Mark weak transcript support as weak. Do not promote keyword evidence into a strong claim.

## Evidence Rules

- Transcript evidence and synthesis are separate.
- Evidence records point to source course, video title, transcript path, and VTT timestamps when available.
- Evidence notes are paraphrases, not quotations.
- A concept can be first-principles synthesis, but it must not pretend to be directly stated in a lecture unless the transcript cue supports it.

## Clustering Rules

- Themes are broad recurring problems shared across courses.
- Subthemes are smaller mechanisms inside a theme.
- Concepts are canonical named ideas that a reader can learn and connect.
- Mathematical primitives are reusable patterns that show up in many concepts.
