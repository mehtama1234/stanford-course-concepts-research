Vision Transformers — how cutting an image into patches lets attention see

A transformer built for text reads by moving its attention over a sequence of words — asking 'which words matter most right now?' and blending them together. But an image is not a sentence; it is a grid of pixels. How can the same machinery that conquered language see a picture? The answer is simple: chop the image into small rectangular patches, flatten each patch into a vector, and treat the sequence of patches exactly like a sentence of words. Here is the idea, a real measurement showing it works, why grouping patches like words is so powerful, where it struggles, and how this one unification became a foundation for models that read and see together.

1 · The problem — transformers conquered language but images are not sequences

A transformer works by attending: for each word, it looks back at all the earlier words, decides which ones matter, and blends them together to build a richer understanding. This 'read selectively' mechanism is powerful — it is the entire engine of large language models. But language is already a sequence of symbols called words. An image, by contrast, is a grid of numbers — pixels arranged in rows and columns, with no obvious order to move through them.

So the question is direct: can a transformer see an image at all? Or does it need a completely different architecture designed for grids?

2 · The reframe — cut the image into patches and read them like words

The move. Take the image and slice it up into a grid of small square patches — say, a picture of a cat split into, say, 16 small rectangles, each roughly the size of a cat's nose or ear. Flatten each patch into a single vector (a row of numbers), just as a word is a vector. Now you have a sequence of patches in a fixed order, exactly like a sentence of words. Feed that sequence into a transformer — the same attention and stacking you use for language — and let it learn. That is a vision transformer (ViT for short). One machine, language and vision both, by treating a picture as a sentence of patches.

The hidden quantity is which patches of the image attend to which others — the same learned focus used for words, now deciding which regions of a picture should inform each other.

3 · Seen on a real run — patches of the same object attend to each other

We cut a 32-by-32-pixel image into 16 equal patches (a four-by-four grid of rectangles) and marked which patches contained the object. Then we ran one pass of self-attention — the mechanism that decides what to look at — and measured: when an object patch looks back over all 16 patches, how much of its attention weight goes to the other object patches?

The discovered fact: an object patch sends 0.46 of its attention to the other object patches, where blind random chance would send 0.25 — the model doubles the chance. Even without any training, the attention mechanism has a built-in bias toward binding together patches that are nearby and similar in value — like with like. With a trained vision transformer, this grouping becomes far sharper.

4 · Why patches work like words — attention groups related parts regardless of layout

The power lies in attention's core idea: 'ask what you are looking for and match against what each other element has to offer.' For words in a sentence, this finds the ones related by meaning or role. For patches in an image, this finds the ones with similar pixels or that sit together spatially — or later, after the model learns, patches that make up the same object, the same texture, the same feature, whether they sit next to each other or not. Patches of a dog's ear, tail, and paw can be scattered around the image, but attention can bind them together into a concept of 'dog-ness' — the same way attention binds 'the', 'cat', and 'sat' into an idea of a sentence. Because the operation is learned and not hand-coded, the model discovers which spatial and visual relationships matter. Because attention reaches across the entire grid at once, a dog's head and back can connect even if they are far apart — the layout does not force a local, myopic view. And because patches preserve some spatial structure (a nearby patch is likelier to be part of the same object), the mechanism has an inductive bias that helps it along.

5 · The one real weakness — patches lose detail and need mountains of data

The cost is that patches are lossy. A 16-by-16-pixel patch, or even a 32-by-32-pixel one, throws away fine detail — a subtle texture, a thin edge, a small object. Older convolutional networks process every pixel individually and can capture crisp local features; patches, by design, trade that resolution for speed. A trained vision transformer needs far more data to learn well than a convolutional network does — it lacks the built-in inductive bias that convolutions encode (the idea that nearby pixels are related). Our untrained patch-attention demo shows only the mechanism, not a trained ViT; a real trained one learns much sharper groupings, but only after seeing millions of images. For small datasets, convolutions still win.

6 · The surprise — one architecture sees text, images, audio, and video

The unity is profound. The same transformer block — the 'attend then blend' step — stacked into layers, works on any sequence. Words are sequences in time; image patches are sequences in space; audio spectrograms are sequences in time and frequency; video is a sequence of frames, each a sequence of patches. By treating each as a flat sequence of tokens, one architecture handles them all. This is why the big models today are multimodal: they embed text and images into the same space using variants of attention, so a model can reason about both a photo and a caption at once. Embeddings turn meaning into geometry, and positional encoding supplies the order; both apply to patches just as they do to words. The result is a single machine for sensing and reasoning across modalities — a consequence of realizing that vision and language are both just pattern-finding in sequences, and attention is the universal pattern-finder.

7 · Where it is used in practice — Treat image patches as word tokens for unified vision and language

Vision transformers are used in image classification, object detection, and visual question answering systems across industry and research. Multimodal models like those that process both images and text use vision transformers to encode images, allowing a single architecture to reason about vision and language together. Medical imaging systems use vision transformers for disease detection and diagnostic support.

An image is divided into a grid of small square patches—for example, a photograph might be cut into a grid of rectangular regions. Each patch is converted to a vector (a sequence of numbers) and treated exactly like a word token in a language model. The same transformer blocks that process word sequences process patch sequences: attention allows each patch to see and relate to all other patches in the image, regardless of distance. Early blocks learn to identify textures and edges; later blocks recognize parts and objects.

Patches sacrifice fine detail for computational efficiency and the ability to use the same architecture for images and text, but they require much more training data than convolutional networks because they lack the built-in spatial inductive bias that convolution provides.

the run recipe — reproduce every number above

Cut a 32-by-32-pixel image into 16 equal square patches (a four-by-four grid). Label which patches contain the object (4 patches in this case). Run one untrained self-attention pass: for each object patch, measure the fraction of attention weight it sends to the other object patches. Compare to the baseline: if attention were random, that fraction would be 0.25 (3 targets out of 16 total patches).

attention_weight_to_target = sum of attention weights from object_patch to other_object_patches random_baseline = (num_object_patches - 1) / total_patches = 3/16 = 0.25 measured = 0.46 measured / random_baseline = 0.46 / 0.25 = 1.84 times chance
