Transformer Block

A repeating layer inside an AI system that lets information flow between different positions, updates each position by combining what it learns, and holds onto old information while adding new updates.

What real-world problem is this about?

Imagine you're reading a long email on a phone screen that shows only one sentence at a time. You read "The bank is closed on Sundays." To understand what "bank" means here, you need to scroll back and see "The river ran past the old bank." Your brain is finite—you can't hold all the context at once. You need a system that repeatedly looks at the relevant parts, updates what you understand, and carries important ideas forward to the next thought. That's what the system inside an AI does when processing text.

Why does this problem exist?

Understanding complex text or images requires multiple passes. On the first pass, you might spot that "bank" appears near "river." On the second pass, you notice grammar connects it to a verb. On the third pass, you link it to earlier context about geography. A single lookup doesn't build this layered meaning. You need a reusable recipe that you can repeat: look at what connects to what, reshape the information based on that connection, keep what you learned, and run again. That's why layers stack.

What is the mathematical idea underneath?

A transformer block has four pieces that work together. First, multi-head attention mixes information: for each position, measure how similar it is to every other position using a dot product (the sum of multiplied pairs of numbers), then scale that result to keep numbers in a reasonable range, and use those similarity scores as weights to average the information at all those positions. This scaling prevents any one similarity from taking over. Second, a feed-forward network (a small learned function that runs separately at each position) reshapes the mixed information—like adding learned color to a black-and-white image. Third, residual connections (adding the original input back to the output at each step) preserve old information so it doesn't disappear when data moves through layers. Fourth, layer normalization (centering and rescaling the numbers) keeps all values in a comfortable range, which makes the training process (tuning the dials) stable and reliable. These four pieces fit together: mix → reshape → carry old state → keep numbers in range.

Why is this concept important?

This structure lets you build deep systems without them falling apart. You can stack hundreds of layers using this pattern because the old-state connections carry learning signals backward during training, and normalization stops the numbers from exploding. The same block pattern shows up in language models (the systems that write text), vision systems (that understand images), and generative models (that create images or text). It's the universal recipe for depth.

What breaks without it?

Without the mixing step, positions can't learn to depend on each other—each chunk operates blind. Without the reshaping step, the block can't perform complex learned transformations at each position. Without old-state connections, deep stacks degrade and the learning signal shrinks as it travels backward through training. Without normalization, the numbers explode and training becomes chaotic and unreliable.

Naive Starting Point

A beginner might think one attention layer solves understanding: measure which words matter to each other, then you're done. That captures one layer of relationships—"bank" might learn to look at "river." But the model hasn't yet reshaped that insight into new features, prepared for the next layer, or kept useful old information from disappearing.

Why the Simple Approach Fails

A single attention layer lets positions learn what to focus on, but it doesn't reshape the information or prepare it for further layers. If you then stack more attention layers without old-state paths or normalization, the learning signal shrinks exponentially as it travels backward through hundreds of multiplications during training. The model learns too slowly. Without per-position reshaping (the feed-forward network), the model can't extract complex patterns—it just blends what's nearby.

The Mathematical Object

The thing you inspect and modify during training is the set of weight matrices inside the attention heads (how to measure similarity), the feed-forward weights (how to reshape), and the normalization parameters (learned rescaling and recentering). These weights collect the model's learned recipes for reading dependencies, transforming information, and keeping numbers in range. During actual use after training, these weights stay fixed and operate on the input positions step by step.

The Operation

Take the current state at all positions (their numerical representations). Measure similarity between every pair of positions using attention. Use those similarities to create a weighted average of all information, done separately for each position and each independent attention channel (a channel is one copy of this process running in parallel). Combine the outputs of all channels. Add the original input back to preserve old information. Apply the reshaping function to each position. Add the original input again. Rescale the resulting numbers. Pass the output to the next layer.

Worked Mini-Example

Suppose three positions hold numbers for "the river bank." Attention measures: position 2 ("river") has similarity score 0.7 to position 3 ("bank"), 0.3 to position 1 ("the"). Position 3 ("bank") has similarity 0.8 to position 2 ("river"), 0.2 to position 1 ("the"). After converting similarities to weights that sum to 1, position 2 outputs 0.7 × numbers[3] + 0.3 × numbers[1], a blend emphasizing "bank." Position 3 outputs 0.8 × numbers[2] + 0.2 × numbers[1], emphasizing "river." The reshaping function then adjusts each position's numbers separately—for instance, position 3 might learn to activate certain features that mark "bank" as a noun when preceded by "river." Old-state connections add back the original numbers so information survives. Rescaling adjusts the final result. The layer passes its output to the next layer for another round.

What the Lectures Emphasize

The Stanford lectures on transformers emphasize that a single layer is not automatic—it's a repeatable unit. The course builds from raw text through chunking (tokenization), converting chunks to numbers (embeddings), and then repeated transformer layers. Each layer performs the same steps: blend information across positions (attention), reshape each position (feed-forward), preserve old information (old-state paths), stabilize numbers (normalization). Stacking many layers with these four pieces creates the depth that captures complex patterns. The layer is not just attention; it's the complete unit that makes deep learning work.

Common Misunderstanding

Many beginners believe a transformer layer is only attention. In fact, attention is one part—the communication step. The layer also needs per-position reshaping (feed-forward), preservation of old information (old-state paths), and numerical stabilization (normalization). Attention tells you what to read; the reshaping function tells you what to write; old-state paths prevent loss of information; normalization prevents numbers from exploding. Remove any piece and training breaks.

How to Recognize This in a New Paper or Model

When reading papers, spot this pattern when a model alternates between spreading information widely (attention or similar mechanisms that let distant positions interact) and local reshaping (learned functions per position), adds old state back (old-state or skip paths), and repeats. It might be called an encoder layer, decoder layer, DiT (diffusion transformer) layer, ViT (vision transformer) layer, or cross-attention layer. The name varies, but the structure is the same: mix → reshape → preserve → stabilize → repeat.

Connected Concepts

In CME295 (Transformers and Language Models), the layer is the core unit of systems that write text. In CME296 (Diffusion and Vision), the same layer architecture appears in systems that understand images and generate images. In CS224R (Deep Reinforcement Learning), models trained on decision history use transformer or memory layers to compress and plan ahead. The unifying idea: composition (stacking simple units), interaction (attention or memory), and preservation (old-state paths or stored memory) enable learning from complex data.
