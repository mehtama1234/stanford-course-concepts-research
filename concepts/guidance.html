Guidance

Steering generation toward a prompt, class, reward, or constraint.

What real-world problem is this about?

The problem is that pure generation may create plausible samples that do not match what the user asked for.

Why does this problem exist?

Generation needs both freedom and control: enough freedom to make rich outputs, enough constraint to satisfy the condition.

What is the mathematical idea underneath?

Guidance modifies the update direction during sampling so the path favors samples consistent with the condition.

Why is this concept important?

It makes image and video models controllable by text, labels, layouts, or preferences.

What breaks without it?

The model may produce realistic but irrelevant outputs.

Naive Starting Point

Start with the simplest version: The problem is that pure generation may create plausible samples that do not match what the user asked for. A beginner might try to solve this with a fixed rule, a lookup table, or one direct guess. That works only while the situation is tiny and clean.

Why the Simple Approach Fails

The simple approach breaks because generation needs both freedom and control: enough freedom to make rich outputs, enough constraint to satisfy the condition. Once the input grows, feedback arrives late, or many explanations compete, the system needs a reusable mechanism instead of a special case.

The Mathematical Object

The useful object is the thing the model can change or compare while learning Guidance: Guidance modifies the update direction during sampling so the path favors samples consistent with the condition. Think of it as the handle the algorithm can grab.

The Operation

The operation is to apply that object repeatedly: read the current situation, produce a numerical signal, and use feedback or comparison to adjust the next step. For Guidance, this is the move that turns a vague goal into an executable procedure.

Worked Mini-Example

Mini-example: a model can generate a beautiful image of a bear, but the prompt asks for a teddy bear reading a book. If the image is aesthetic but ignores the book, it fails the user's condition. Guidance is the family of tricks that steers generation toward a prompt, class, layout, or reward while still allowing variation. CME296's evaluation lecture uses prompt adherence as a motivating example: an image can look good and still be bad because it does not represent the prompt.

What the Lectures Emphasize

CME296 treats guidance and evaluation together through the tension between visual quality and prompt adherence. Earlier guidance material explains how generation can be conditioned; the evaluation lecture makes the failure concrete by asking students to judge images against a prompt. This emphasizes that controllable generation is not only about realism. It is about satisfying the instruction that defines the sample's purpose.

Common Misunderstanding

A common misunderstanding is that better image quality automatically means better prompt following. The lecture example separates aesthetics from adherence: a polished image can still fail if it depicts the wrong thing. Guidance exists because generation needs both freedom and constraint.

How to Recognize This in a New Paper or Model

In a new paper, recognize guidance when sampling directions are modified by a condition: text prompt, class label, layout, reward model, safety constraint, or preference signal. The method may be classifier guidance, classifier-free guidance, control signals, reward guidance, or prompt adherence optimization. The shared primitive is steering: change the path through sample space so plausible outputs also satisfy the goal.

Connected Concepts

The same primitive reappears near diffusion, reward modeling, agents and tools. Across the three courses, the shared pattern is feedback, search: choose what to keep, how to move, what feedback means, or how to measure whether the behavior really improved.
